# F7 No abrupt cuts

Model: S · Written by the owner 2026-11-11 from design rev 40, plan rev 19
Status: ready (second in Arjun's order)

## What to build
Friends' playtest F7: after the war chest is taken you are teleported outside. Walk or fade every
such moment. **List them all first** (every place the game moves a captain or unit instantly, or
cuts the camera), and send the list to the owner before changing anything: Arjun picks walk or fade
for each one where it isn't obvious.

## Done when
For each listed moment, a test in `game/store/r_F7.mjs` shows no position jump over 2 m between
frames for the moved captain (or a fade covering it), plus `crown2sim.mjs` and `crown2online.mjs`
passing.

## Design rules it relies on
None found in the design doc; the friends' playtest note is the rule.

## Where to start in the code

- Find the rest with `graphify query "set position teleport respawn"` and grep for direct `.x =`/`.z =`
