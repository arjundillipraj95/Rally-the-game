# C1 Champion framework

Model: O · Written 17 Nov from the design doc (rev 116, Champions section) and the code on `launch26` (d972bcb)
Status: card waiting for go

## What to build
A champion is one data file (under 300 lines): name, class, stats against the baselines, weapon, mount, 3-hit combo,
special attacks 1 and 2, champion ult, army ult, soldiers to recruit, influence on army. Numbers in config tables.
Shared level path 1-10 from match XP; special 1 at level 3, special 2 at 5, both ults at 7. Respawn stays on the
castle clock (CASTLE7). Health as shares of an infantryman; counter rule 120%. Every champion has a mount, used as
today (Ride). Champion chosen by setting or `?champ=` for now (lobby pick is S1-12).

## What the code has today (read 17 Nov)
- One captain for everyone (`mkUnit` in `core/sim/match.js`, `STATS.captain`): hp 150 (1.6 footmen, design 4x),
  a human hits 30 and a bot 22 (`HUMAN_CAPTAIN`); 3 weapons switched by a button (sword, spear, javelins).
- Captain power comes from the army's footman upgrades (`CAPTAIN_TIERS`, `applyFootTier`), not from levels.
  No XP or levels exist in a match (`XP` in config is the account rank after the battle).
- Shared captain moves: block/parry, evade, jump + leap slam, bash, heavy blow, rhythm and streak finishers,
  execution, duels, horse charge (`CHARGE`), shield-wall push, rally cry (`RALLY`). No ability slots or buttons.
- Recruits: one global list (`RECRUITS` = footman, archer). The footman is sword and shield, spear from upgrade 1.
  Army size: 5 + the side's castles shared out (`capOf`, `CROWN2.base/perCastle`). Aura upgrade still sold.
- Spear on a mounted man: x3 to the horse, and half of all other hits go to the horse (`hit()` in melee.js).
- Joined phones: the captain's state rides in `net/netgame.js` (788 lines, already over 500).

## Cards (each its own commit, test and go)
- **C1a Champion file and pick.** `game/src/champions/` (registry + one file each) and a `CHAMPS` config table.
  First file: `legionary`, today's captain as a champion (same numbers, 3 weapons), the default, so nothing changes.
  `?champ=<id>` and a setting choose yours; bots get the default. Champion id on every phone (new `net/champnet.js`).
  Done when: `r_C1a` default battle identical to today (r_SPLIT method); joined phone shows the host's champion ids.
- **C1b Levels and XP.** `LEVELS` table (XP to next: 100, 120, 200, 230, 280, 320, 360, 400, 440) and XP sources
  (soldier 6, champion 60 + more above your level, camp 40, buff camp 80, castle capture 100 shared, Sceptre 200,
  trickle near objectives). Stats per level replace `CAPTAIN_TIERS` for champions. Level badge and level-up moment.
  Kept through death. Done when: `r_C1b` bot battle: XP from each source, levels 3/5/7 unlock, average bot ends 8-9,
  same level on the joined phone.
- **C1c Ability slots.** Special 1, special 2, champion ult, army ult: cooldowns, locked until their level, pressed by
  humans (host and joined) and bots. Shared blocks: dash, circle, cone, projectile, buff. Temporary buttons until the
  battle screen (S1-15). Done when: `r_C1c` with a test champion (store only): each slot locked, unlocks, fires, same on
  the joined phone.
- **C1d Health shares and counter rule.** `UNITS` table: infantry 100%, archer 60%, champion's horse 200%, champion
  400% (plus each champion's own); hits: infantry 20%, arrow 10%, champion 34%, behind 1.5x. Counter 120%: spears on
  horses (horse, not rider), arrows on infantry, cavalry on archers (when C2 adds cavalry). Castle turret and camp
  damage rescaled so their timings stay. Done when: `r_C1d` hits-to-kill match the design table; castle take times
  within 10% of today.
- **C1e Army: recruits, influence, size.** Recruit list per champion, influence on army as a hook (damage taken or
  dealt, speed, health; range), army size by class (Vanguard 5 +5/+3, Striker and Raider 3 +3/+3). Aura upgrade hidden.
  Done when: `r_C1e` recruit menus follow the champion; influence on and off by range; sizes match the table.
- **C1f Mount for all.** Mount and speed (on foot and riding) from the file; Ride as today. Base-to-Crown walk
  rechecked (27 s today, design 20-25). Done when: `r_C1f` each test champion rides; speeds match the file.

Every card: crown2sim and crown2online pass (no roles flag on launch26: one run each), r_PERF1c, lag no worse.

2. Human and bot champions get the same numbers (today a human hits 30, a bot 22); bots stay weaker by difficulty.
3. Today's shared moves for champions: keep block/parry, evade, jump, duel/execution, horse charge; drop the weapon
   switch and javelins (one weapon each); the battle screen card decides the rest.
4. Temporary ability buttons: three small round buttons above Attack; army ult on today's Rally button.
5. Spear on horse goes from x3 (and half of all hits) to 120% and the horse only: horses get much tougher. OK?
6. Champion kill above your level: +10 XP per level of difference.
