# F17 More captain clips: spin, leap, spear, javelin, shield bash, knockdown (Cosindra)

Model: Opus · Written and built 2026-11-13 in Arjun's animation chat (his go: "lets do this and push to main")
Status: built, tests below; horse and rider not done (waiting on the horse download).

## What was built
1. Sources (free, commercial use, no attribution): 12 MotionSmith gallery clips from cosindra.ai (Arjun's free
   account; the free take of each), UE5 Manny skeleton. Kept out of the repo (raw files are not redistributed);
   they sit in Arjun's Downloads as `MotionSmith_*_InPlace.glb`.
2. `tools/models/cosindra_export.py` (Blender's Python, `pip install bpy`): one clip -> JSON of each body part's
   turn from the T-pose, 30 fps. `tools/models/extra.py`: puts those on the shared 22-bone skeleton and adds them
   to `captain_anim.glb` and `soldier_anim.glb` (run after `prep.mjs`, which rewrites the files without them).
   Clip names, trims and loop seams: the EXTRA table in extra.py. Each file +~350 KB (41 clips).
3. Wiring (`game/src/config.js` ANIM, `render/heroes.js` clipHero): the clip for each swingKind by weapon.
   Sword: combo finisher (4) = `spin` (was slash3), leap (2) = `leapSmash` (head to toe; the game's own jump
   lifts him), held heavy blow (5) = `overhead`, shield bash (6) = `shieldBash` (5 and 6 were code poses).
   Spear: thrust/skewer (3, 5) = `spearThrust`, wide blow (4) = `slashWide`, upper body `spearIdle` while he
   stands or walks. Javelins: throw (4) = `javThrow`. `unit.act` 'knockdown' / 'getUp' are ready for the roles'
   knockdowns (nothing sets them yet). `slashBack` and `getUp` are loaded, unused.
4. Soldiers in battle still use code poses (unchanged): their file has the clips for when they get clip rigs.
