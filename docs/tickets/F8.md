## What to build
Scope is the first part of plan P8.2 and P8.3, for captains only. Soldier batching waits for F1.
1. Model prep script (new `game/tools/models/`, or `tools/models/` at repo root, whichever matches the existing layout): reads the two Mixamo packs, checks each body and clip (scale, axis, `mixamorig:` bone names), copies the clips onto the one shared skeleton, and writes GLB or the format the loader already uses into `game/public/models`. Never edit the uploads in place.
2. Captain body: the `cap` pack body (`white_mesh.fbx`), with its clips, replaces the code-posed captain in `render/heroes.js`.
3. Captain clips mixed by game state, with blends. Upper body separate from legs so attack-while-running works (P8.3).
4. Soldier body: the `sold` pack body and its clips are prepared and loadable (P8.2), but not yet drawn in battle. F1 uses them.
5. Clips to wire to the captain (from the packs): idle, walk, run, strafe left and right, 180 turn, sword slash (the 3-hit combo), attack and boosted attack, block and block idle, impact (hit reaction), death, kick, crouch, sheath sword, power up, casting.
6. Where the pack has no matching clip (heavy hit, knockdown and get-up, war cry, shield bash, spear, bow, axe, spin, execute), keep today's code pose for that move and note it in the card's Status.
